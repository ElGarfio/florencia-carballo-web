INSTRUCCIONES PARA IMÁGENES
============================

Esta carpeta es donde deben ir todas las imágenes de las obras.

Nombres recomendados:
- obra-1.jpg
- obra-2.jpg
- obra-3.jpg
etc.

O nombres descriptivos:
- sol-naciente.jpg
- canales-brujas.jpg
- rio-sena.jpg

IMPORTANTE:
- Usar solo minúsculas
- Sin espacios (usar guiones: - )
- Formatos permitidos: .jpg, .jpeg, .png
- Tamaño recomendado: 600-1000px de ancho

Cuando agregues una obra nueva en el panel admin (/admin),
el sistema te pedirá que subas la imagen. Las imágenes se
guardarán automáticamente en esta carpeta.
